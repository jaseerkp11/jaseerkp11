# BlockMe helper — iPhone

Do **not** open the file from Files, GitHub, or jsDelivr. Those send **plain text**, so iPhone shows code.

## Open this in Safari (type it or tap it)

https://htmlpreview.github.io/?https://github.com/jaseerkp11/jaseerkp11/blob/cursor/blockme-line-helper-9059/blockme/helper.html

You should see a **green grid**, not code. Then Share → Add to Home Screen.

If that page is blank, wait 2 seconds (it loads GitHub). If it still fails, the next working way is after this site is deployed: `/blockme.html` on the store domain.
